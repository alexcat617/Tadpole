# Rink Radar web app

## Run (required before opening the browser)

```powershell
cd projects/rink-radar/app
npm ci
npm run dev
```

Open **http://127.0.0.1:5173/** — not a file path, not the repo folder in Explorer.

Production build preview (after `npm run build`):

```powershell
npm run preview
```

Open **http://127.0.0.1:4173/**
